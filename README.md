# Botamin

Демонстрационный дашборд для анализа результатов звонков голосового бота. Помогает увидеть воронку разговора, потери на этапах и изменение показателей между периодами.

В работе я сформулировал задачи аналитика, выделил основные показатели и собрал интерфейс для их сравнения. Демонстрация использует сгенерированные примеры звонков.
